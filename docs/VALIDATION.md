## Не проверено / не входит в эту поставку

- Выполнение на самом Mac пользователя. Инструкция использует переносимые команды Python 3.12 без Linux-specific build dependencies.
- Реальный PostgreSQL/Docker: в текущей среде нет PostgreSQL/Docker. Есть CI-конфигурация SQLite/PostgreSQL 17, которая выполнится после загрузки в GitHub.
- Публичный сервер, домен, TLS reverse proxy, почтовая доставка и интеграции банков/AI.
- OTP/JWT и бизнес-функции из дальнейших Parts.

HSTS includeSubDomains и preload намеренно выключены до проверки домена/поддоменов, поэтому W005/W021 документированы, а не скрыты. Production-проверка и collectstatic не означают готовность Part 1 к открытому размещению с реальными данными.
