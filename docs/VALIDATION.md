PostgreSQL/Docker здесь не запускались. Три пропущенных теста предназначены для PostgreSQL job в GitHub Actions; workflow удалённо не запускался. Проверка конкурентной работы PostgreSQL остаётся перед размещением. Успех SQLite-тестов не заявлен как подтверждение PostgreSQL-нагрузки.

Не выполнялись production-размещение, настоящая SMTP-доставка, отправка сообщений, публикация GitHub, платежи и AI. Нет записи ответов клиента/заявок и загрузки файлов; Part 3 проверяет анкету в памяти. Начальные требования к документам требуют проверки оценщиком перед реальной эксплуатацией. Юридические seed-тексты Part 2 остаются тестовыми.
