## Технические решения

- Backend Python/Django REST Framework, отдельный Ocenka360_BE.
- Mobile JavaScript + JSX, React Native/Expo, NativeWind, i18n, Axios, Zustand, Lucide, анимации. Не TypeScript.
- Next.js JavaScript/JSX, отдельный опубликованный веб-кабинет Ocenka360_FE для оценщика и администратора; публичный маркетинговый сайт сейчас вне объёма.
- Дизайн: Ocenka360_App/design, 64 экрана (40 клиент, 14 оценщик, 10 admin), светлый интерфейс, тёмно-зелёный/салатовый/белый. Допускаются обоснованные улучшения.
- RU/KK/EN, отчёты на русском; только телефоны; приложение работает с интернетом.
- Вход по одноразовому коду email; SMS отложены из-за стоимости. ИИН не пароль.
- Выдача по частям ZIP-архивами, без автоматического push/deploy. Пара Backend → Mobile; веб-кабинет отдельными Parts.
- Домен ocenka360.com только предполагается; доступа к ocenka360.kz/его поддоменам нет.

## Заявка и оценка

Каталог → ориентировочная стоимость услуги → адаптивная анкета → документы/фото → проверка и явное подтверждение → аванс 2 000 ₸ → рассмотрение мамой → запрос дополнений или утверждение цены → согласие клиента и доплата → выполнение → загрузка PDF мамой → уведомление.

Начало выполнения — отдельное действие оценщика после согласования и оплаты. Проверка заявки не считается автоматически началом платного выполнения. Отмена до начала, отказ компании или несогласие с ценой до начала — полный возврат; после начала — индивидуальное рассмотрение. Изменение цены требует согласия клиента. Не обещать мгновенный возврат до банковского подтверждения.

Клиент предлагает интервал, мама подтверждает. В Астане выезд включён в цену. Удалённый осмотр квартиры/дома/авто допускается после принятия фотографий оценщиком; фотоинструкция должна описывать необходимые ракурсы. Фото клиента отдельно от фото специалиста. Нельзя автоматически считать пользовательские фото полноценным осмотром.

Обычный срок — до двух дней после осмотра, срочные задания — от часа; конкретный срок и возможность подтверждает оценщик. Для удалённого заказа отсчёт — после подтверждения достаточности материалов. Срочность/ночная работа — согласуемая доплата.

Готовый PDF загружает мама, клиент скачивает. Бумажный оригинал забирают в офисе; доставка за счёт клиента согласуется через WhatsApp. Готовность PDF и бумажного экземпляра — отдельные события. После завершения — кнопка отзыва в 2ГИС, без автоматической публикации отзыва.

## Документы (со слов владельца, уточняются оценщиком)

| Услуга | Документы |
|---|---|
| Квартира | Техпаспорт, основание собственности (купля-продажа/дарение и др.), справка Ф2, удостоверения собственников |
| Авто/ДТП | Техпаспорт; удостоверение для физлица; свидетельство госрегистрации организации для юрлица; дополнительные материалы ДТП по назначению оценки |
| Нежилой объект | Техпаспорт, основание собственности, Ф2, удостоверение/регистрация юрлица, госакт на землю при необходимости |
| Дом и участок | Техпаспорт, акт приёмки, договор на дом, госакт/договор на землю, Ф2, удостоверение |

Динамические формы и списки обязательности будут уточняться в модуле услуг. Не выдавать этот список за исчерпывающую юридическую норму для любого случая. Проверка полномочий и основания передачи данных остальных собственников нужна до работы с реальными документами.

## Цена и оплата

Средняя цена около 20 000 ₸ по словам владельца — не утверждённый тариф. Калькулятор цены услуги должен опираться на редактируемый прайс, показывать предварительность и окончательное решение оценщика. Сложные активы могут требовать индивидуального предложения. Не вычислять комиссию автоматически как процент стоимости объекта без согласованного правила.

Аванс засчитывается в итог; промокоды создаёт администратор. Kaspi Pay, Halyk ePay/интеграции и касса подтверждены пользователем, технические доступы не предоставлены и не проверены. Подтверждение оплаты — серверные данные банка, не скриншот и не возвращение в приложение. Банковская квитанция не тождественна фискальному чеку.

## Уведомления, AI и калькуляторы

WhatsApp Business Platform пользователь не подключает. Автоматические сообщения в обычный WhatsApp не обещаны: push + внутренняя лента + открытие диалога с подготовленным текстом. Отправку WhatsApp подтверждает человек. Комментарии и запросы недостающих документов заменяют полноценный чат в первой версии.

Gemini в первой полной версии: подбор услуги, помощь с формой, проверка комплектности, предварительный анализ фото, черновики описаний для оценщика. Решения и официальные выводы только за специалистом. AI не отправляет деньги, не утверждает цену и не раскрывает чужие документы.

Три отдельные функции: (1) цена услуги по прайсу, (2) ориентировочная рыночная стоимость имущества по источникам рыночных данных, (3) официальный расчёт ущерба ДТП через применимое лицензированное специализированное ПО. Название ПО/поставщик/доступ пока неизвестны. Источник рыночных данных не выбран. Эти зависимости могут расширить число Parts; нельзя подменять их выдуманным расчётом Gemini.

## План Backend

1. Основа, пользователь/роли, admin, системный API — этот архив.
2. Email OTP, сессии/токены, профиль и согласия.
3. Услуги, динамические анкеты и требования к документам.
4. Объекты, заявки и переходы статусов.
5. Защищённые документы, фотографии и инструкции.
6. Прайс, цена услуги, согласование и промокоды.
7. Расписание, выезд/удалённый осмотр, сроки.
8. Банковские интеграции, аванс/доплата, отмены/возвраты.
9. Комментарии, запросы материалов, уведомления.
10. Отчёты, выдача оригинала, задачи и показатели.
11. Gemini, рыночный калькулятор и подключение расчёта ДТП при доступности интеграции.
12. Полный процесс, безопасность, резервное копирование, размещение.

Ориентир: 12 Backend + 12 Mobile + 8 Frontend, всего 32 Part. Это план, а не гарантия числа частей при изменении требований и внешних интеграций.
