# Изменения

## 0.1.0 — Part 1 — 2026-11-15

- Django 5.2.19 / DRF 3.18.3, Python 3.12, зафиксированные зависимости.
- Custom User: UUID, email, роли, языки, телефон, даты; начальная миграция.
- Административная панель с ограниченным управлением пользователями.
- Системный API, публичная конфигурация, собственный профиль, health checks.
- OpenAPI/Swagger, JSON-ошибки, request ID, CORS, базовые лимиты.
- Разделение настроек; production-проверки обязательных параметров.
- Автотесты, Ruff, CI для SQLite/PostgreSQL, русская документация.

Вход по email-коду и все бизнес-модули запланированы на последующие Parts.
